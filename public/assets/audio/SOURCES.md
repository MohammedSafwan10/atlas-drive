# Audio sources

## Racing engine loops

- Source: [Racing car engine sound loops](https://opengameart.org/content/racing-car-engine-sound-loops)
- Creator: domasx2
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Files used: `loop_0.wav`, `loop_3.wav`, and `loop_5.wav`
- Processing: high-pass/low-pass filtering, matched loudness, 48 kHz mono
  conversion, and Ogg/Vorbis encoding with FFmpeg.

Road noise, nitro, collision, near-miss, and interface sounds are synthesized
at runtime with the Web Audio API and contain no external samples.

## Rain loop

- Source: [Rain (loopable)](https://opengameart.org/content/rain-loopable)
- Creator: Ylmir
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- File used: `2.ogg`
- Processing: loudness normalization and Ogg/Vorbis recompression with FFmpeg.

## Thunder variations

- Source: [rain and thunders](https://opengameart.org/node/22231)
- Creator: kindland
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- File used: `Dark_Rainy_Night(ambience).ogg`
- Processing: three distinct thunder passages were trimmed, band-limited to
  reduce the embedded rain bed, faded, loudness-normalized, and encoded as
  compact Ogg/Vorbis files with FFmpeg. A synthesized low-frequency layer is
  retained underneath for impact and as a load-failure fallback.
