# Realistic environment assets

- `../alps_field_4k.webp` — web-optimized from Poly Haven's 8K **Alps Field** panorama (CC0): https://polyhaven.com/a/alps_field
- `boulder.glb` — web-optimized from Poly Haven's **Boulder 01** model (CC0): https://polyhaven.com/a/boulder_01
- `rock.glb` — converted from Poly Haven's **Rock 07** model (CC0): https://polyhaven.com/a/rock_07
- `fern.glb` — converted from Poly Haven's **Fern 02** model (CC0): https://polyhaven.com/a/fern_02
- `grass/` — Poly Haven's **Grass Bermuda 01** model and 1K PBR textures (CC0): https://polyhaven.com/a/grass_bermuda_01
- `trees/pine.glb` — optimized from Poly Haven's **Pine Sapling Small** model (CC0): https://polyhaven.com/a/pine_sapling_small
- `trees/island.glb` — optimized from Poly Haven's **Island Tree 02** model (CC0): https://polyhaven.com/a/island_tree_02
- `trees/jacaranda.glb` — optimized from Poly Haven's **Jacaranda Tree** model (CC0): https://polyhaven.com/a/jacaranda_tree
- `pine_tree.png` and `broadleaf_tree.png` — project-specific transparent game cutouts generated with the built-in OpenAI image-generation tool.

Poly Haven assets were downloaded at 1K PBR texture resolution and packaged as self-contained GLBs. The boulder geometry was simplified for real-time browser rendering.
